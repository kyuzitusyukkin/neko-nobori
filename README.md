# ねこのぼり

スライムの猫が、キャットタワーをのぼっていくミニゲームです。

タップすると反対がわのかべにジャンプします。かべから出ているトゲやしましまブロックをよけながら、おさかなを食べて点をかせぎましょう。おさかなを食べるほど猫は大きく育ちますが、体が大きく・ジャンプがおそくなります。ねこじゃらしを取ると少しやせます。おさかなやねこじゃらしを続けて取るとコンボでボーナス点。取りのがすと Miss になり、3回でおしまいです。

はじめて遊ぶときは、遊びながらおぼえるチュートリアルがはじまります。

遊ぶ：https://kyuzitusyukkin.github.io/neko-nobori/
